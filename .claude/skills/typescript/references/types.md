## Type vs Interface

**Use `interface` for:**
- Entity definitions (Product, Order, User)
- Objects that will be extended
- API request/response contracts

**Use `type` for:**
- Union types
- Intersection types
- Mapped types
- Aliases for primitives

```typescript
// Interface for entities
export interface Product {
  id: number;
  name: string;
  price: number;
}

// Type for unions
export type BlockType = 'hero' | 'features' | 'products';

// Type for intersections
type ProductWithStock = Product & { inventory: number };
```

## Optional vs Nullable

**Optional (`?:`)** - Field may be missing entirely

```typescript
interface ProductPayload {
  name: string;
  salePrice?: number;  // May not be provided at all
}
```

**Nullable (`| null`)** - Field exists but value is null

```typescript
interface Product {
  id: number;
  salePrice: number | null;  // Always present, may be null
}
```

**Both** - For database fields that are nullable AND optional in requests

```typescript
interface Product {
  salePrice?: number | null;  // May be missing OR explicitly null
}
```

### This Codebase Convention

| Field Type | Pattern | Example |
|------------|---------|---------|
| Database nullable | `T \| null` | `salePrice: number \| null` |
| Request optional | `T?` | `salePrice?: number` |
| Optional + nullable | `T? \| null` | `salePrice?: number \| null` |

## Utility Types

### Partial<T> - All Properties Optional

```typescript
// Update payloads - all fields optional
interface UpdateProductPayload extends Partial<ProductPayload> {}

// Equivalent to:
interface UpdateProductPayload {
  name?: string;
  price?: number;
  salePrice?: number;
}
```

### Pick<T, K> - Select Specific Properties

```typescript
// Only expose certain fields to public API
type PublicProduct = Pick<Product, 'id' | 'name' | 'price' | 'imageUrl'>;
```

### Omit<T, K> - Exclude Properties

```typescript
// Create payload without id (generated by DB)
type CreateProductPayload = Omit<Product, 'id' | 'createdAt' | 'updatedAt'>;
```

### Required<T> - All Properties Required

```typescript
// Ensure all config values are present
type RequiredConfig = Required<PartialConfig>;
```

## Record Types for JSONB

Use `Record<K, V>` for flexible key-value data stored in PostgreSQL JSONB.

```typescript
// backend/src/types/index.ts
export interface Product {
  id: number;
  name: string;
  // Flexible attributes from JSONB column
  customAttributes?: Record<string, any>;
}

// More specific when structure is known
export interface ProductFilters {
  attributes?: Record<string, string | string[]>;
}
```

### WARNING: Avoid `any` in Records

**The Problem:**

```typescript
// BAD - No type safety for values
customAttributes: Record<string, any>;
```

**The Fix (when possible):**

```typescript
// GOOD - Typed attribute values
customAttributes: Record<string, string | number | boolean | string[]>;

// BETTER - Known attribute structure
interface CustomAttributes {
  brand?: string;
  volume?: string;
  ingredients?: string[];
}
```

## API Contract Types

### Request Payloads

```typescript
// backend/src/types/index.ts
export interface OrderPayload {
  customer: {
    name: string;
    email: string;
    phone?: string;
    address: string;
  };
  items: Array<{
    productId: number;
    quantity: number;
    variantId?: number;
  }>;
  total: number;
  promoCode?: {
    id: number;
    code: string;
    discount: number;
  };
}
```

### Response Types

```typescript
// Paginated response wrapper
export interface PaginatedResponse<T> {
  data: T[];
  total: number;
  page: number;
  limit: number;
  hasMore: boolean;
}

// Usage
type ProductsResponse = PaginatedResponse<Product>;
```

### Error Response

```typescript
export interface ApiError {
  message: string;
  code?: string;
  errors?: Array<{
    field: string;
    message: string;
  }>;
}
```

## Design Token Types

Complex nested types for theme system.

```typescript
// backend/src/types/theme.ts
export interface DesignTokens {
  version?: string;
  color: ColorTokens;
  typography: TypographyTokens;
  spacing: SpacingTokens;
}

export interface ColorTokens {
  brand: {
    primary: string;
    secondary: string;
    accent: string;
  };
  semantic: {
    background: {
      primary: string;
      secondary: string;
      elevated: string;
    };
    text: {
      primary: string;
      secondary: string;
      inverse: string;
    };
    feedback: {
      success: string;
      warning: string;
      error: string;
    };
  };
}
```

### Deep Partial for Theme Updates

```typescript
// Allow partial updates to nested theme structure
type DeepPartial<T> = {
  [P in keyof T]?: T[P] extends object ? DeepPartial<T[P]> : T[P];
};

type ThemeUpdate = DeepPartial<DesignTokens>;

// Now valid:
const update: ThemeUpdate = {
  color: {
    brand: {
      primary: '#ff0000',  // Only update one nested field
    },
  },
};
```

## Express Request Extension

```typescript
// backend/src/middleware/authMiddleware.ts
export interface AuthenticatedRequest extends Request {
  user?: { email: string };
  userId?: number;
  adminId?: number;
  role?: string;
}

// Usage in routes
router.get('/profile', authenticate, async (req: AuthenticatedRequest, res) => {
  const userId = req.userId;  // TypeScript knows this exists
});
```
